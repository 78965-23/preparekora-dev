PREPAREKORA CLEAN WORKSPACE
===========================

FRONTEND
--------
Upload these three files to the same GitHub Pages root folder:
- index.html
- style.css
- preimg.js

Keep the existing API_BASE URL and Cloudflare/Firebase secrets in the Worker only. No secret keys belong in these frontend files.

CLOUDFLARE WORKER
-----------------
Replace the current Worker script contents with worker.js from this package, then deploy the Worker. Keep the existing Cloudflare environment variables/secrets and allowed origin configuration unchanged.

The updated Worker:
- Keeps the existing login, catalog and question APIs.
- Makes MCQ explanation optional (if supplied, it must be bilingual).
- Adds admin-only POST/GET /api/admin/image-generations routes.
- Allocates subject/topic-specific unique Image IDs and stores image generation metadata in Firebase RTDB.

IMAGE STORAGE
-------------
Question records and Image ID metadata are stored in Firebase RTDB.
Generated PNG files are downloaded locally to the admin's device. The ZIP contains the PNG pages and a small export-details JSON file; PNG binary data is not stored in RTDB.

IMAGE ID FORMAT
---------------
PK/IMG/{SUBJECT_CODE}/{TOPIC_CODE}/{MMYY}/{UUID}

Image IDs are generated by the Worker and conditionally written to RTDB to prevent duplicates. Question IDs continue to be generated by the existing question API.

DEPENDENCIES
------------
The frontend loads html2canvas, QRCode.js, and JSZip from public CDNs. An internet connection is needed for these libraries and Google Fonts.
